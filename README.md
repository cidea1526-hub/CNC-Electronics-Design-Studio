# CNC Electronics Design Studio

مكتبة تفاعلية لمخططات توصيل الإلكترونيات لآلات CNC والطابعات ثلاثية الأبعاد والليزر. الصفحة ملف واحد (`index.html`) يعمل في المتصفح بدون تثبيت أو خادم.

An interactive library of wiring diagrams for CNC machines, 3D printers and lasers. Single static file, no build step.

## المزايا

- اختيار نوع الآلة والمقاس ومستوى الإلكترونيات (اقتصادي / متوازن / ممتاز).
- مخطط توصيل قابل للتكبير والسحب، مع أسماء الأطراف وأسماء الإشارات وألوان الأسلاك.
- النقر على أي قطعة أو سلك لعرض بياناتهما وتمييز الوصلات.
- جدول المكوّنات، وجدول التوصيل (Pin-to-Pin)، وفحص التحقق، والافتراضات والمصادر.
- **تصدير المخطط:** PDF (A3 أفقي) أو صورة PNG للطباعة.
- **قائمة الشراء لكل دائرة:** كمية كل قطعة وموديلها ومواصفاتها ومكان استخدامها، مع مستلزمات التوصيل غير المرسومة. تُنزَّل PDF للطباعة (فيها خانة اختيار وعمود للسعر) أو CSV يفتح في Excel.
- ملف ZIP كامل للمشروع (SVG وCSV وإعدادات الفيرموير).

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو انشره على GitHub Pages:

1. ارفع `index.html` و`README.md` إلى المستودع.
2. من **Settings ← Pages** اختر الفرع ومجلد `root`.
3. افتح الرابط الذي يظهر بعد دقيقة تقريباً.

يحتاج الاتصال بالإنترنت عند الفتح لتحميل مكتبتي jsPDF وJSZip وخط IBM Plex من cdnjs وGoogle Fonts.

## تنبيه

البيانات أولية (Preliminary). كثير من القطع مفترضة بمواصفات عامة، وبعضها غير مؤكد وموسوم بذلك داخل الصفحة. راجع الداتاشيت الرسمي لكل قطعة قبل التوصيل أو الشراء، ولا تعتمد على المخطط وحده في الدوائر التي تعمل على جهد الشبكة الكهربائية.
